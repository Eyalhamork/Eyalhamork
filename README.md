## 🚀 Featured work

### [Martiva](https://martiva.app): a multi-sector marketplace for Liberia
`Next.js 16` `Expo` `TypeScript` `Supabase` `Redis` `OpenAI` `Resend`

A single entry point to Liberia's economy: a marketplace, jobs and CVs, tenders and contracts, and a verified directory of NGOs and government agencies. It runs as a PWA plus an iOS/Android app.

- **AI listing wizard:** price suggestions from marketplace data, plus automatic title and description rewrites
- **AI payment reconciliation:** when the mobile money API fails, an SMS forwarder matches incoming MoMo messages against uploaded receipts and approves payments automatically
- **Wallet tokens,** including diaspora-sponsored tokens that family abroad send to local businesses
- **Programmatic SEO** with AI-generated alt text and meta descriptions. Before launch, it already has 200+ registered users, 300–500 organic visits and 7–10k search impressions a month
- **Engagement:** weekly digests, trending listings, price-drop alerts, shop health scores, and reviews with seller replies
- **Multi-role dashboards** (admin, moderation, a commission-based agent program), 2FA, and push alerts with an SMS fallback

> Source code is private and available on request.
